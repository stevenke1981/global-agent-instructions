## Adopted rules

| Discussion | Applied policy |
|---|---|
| Engineering kit | Human-operable workflows; discover actual tools before use; portable task routing, interface planning, impact analysis, focused verification, and evidence logs; no invented model or subagent execution; distinguish packaging, installation, discovery, and live execution. |
| Identity router | Choose the intended identity separately from verifying the active session; use confirmed project bindings and hard constraints; distinguish browser, API, CLI, service account, login method, workspace, and channel; verify the relevant target before side effects; protect private mappings and credentials. |

These are policy adaptations, not installation instructions or proof that either package is installed. The conversations' historical test counts, package versions, archive hashes, and download links are not current local verification results. Service checks must use the capabilities actually available at execution time.

The rules are included in codex/AGENTS.md, shared/AGENTS.md, and the AGY template. Existing model bans, spending limits, approvals, coding preferences, and timestamped report naming remain applicable. The contradictory Sonnet review sentence in the shared/AGY delegation section is replaced with the existing authorized-model and risk-based review rules.
